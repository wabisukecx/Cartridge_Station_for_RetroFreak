# MiSTer 管理画面 設計

[English](../FRONTEND_MISTER_MANAGER.md)

## 位置づけ

- MiSTerのScriptsメニューから起動する、テレビとゲームパッド向けの英語の文字メニュー。Linuxの端末（fb_terminal）に描画し、画像ライブラリーや日本語フォントに依存しない。
- 操作は、MiSTer標準が設定済みのパッドを上下・Enter・Escなどのキーに変換する仕組みに乗る。パッド個別のドライバーは持たない。
- 保存済みゲームの一覧と選択は、ConsoleModeに任せる。管理画面は、取り込みと、直前に取り込んだタイトルの起動だけを行う。
- 端末が対話環境でない（ttyでない）場合は起動しない。SSHから実行すると、画面はテレビではなくSSH端末に表示される。
- PCでは `manager --preview` で、リーダーを開かずに画面だけを確認できる。

## 画面

### メイン画面

```text
==============================================================================
 Cartridge Station for RetroFreak / MiSTer FPGA Edition
 Cart: <カートリッジの状態>
 Game: <タイトル>
 <詳細>                                   (高さ21行以上のとき)
 Reader: <リーダーの状態>
 ROM: Verified file available / Not saved / not verified
 Core: Ready / Core/settings not available
 > CHECK / RETRY
   SELECT CARTRIDGE
   DUMP CARTRIDGE
   GAME START
   EXIT TO MiSTer
 <メッセージ または 進捗バー または 確認>
 D-pad: Move   OK: Select   Back: Cancel
==============================================================================
```

- 表示幅は40〜100桁、高さは16行以上。端末が小さいと詳細行を省く。最終行は使わずスクロールを防ぐ。
- 表示するのは印字可能なASCIIだけ。それ以外は空白または `?` に置き換える。
- 実行できない項目には `[unavailable]` を付ける。

### メニュー項目と有効条件

| 項目 | 動作 | 有効条件 |
|---|---|---|
| CHECK / RETRY | リーダーとカートリッジを確認し直す（接続を閉じて再接続） | 処理中でない |
| SELECT CARTRIDGE | 候補の一覧を開く | 候補があり、処理中でない |
| DUMP CARTRIDGE | 確認の後、取り込む | 読み出し対応の候補が選択済み、または自動判定グループがあり、処理中でない |
| GAME START | 確認の後、検証済みROMでゲームを起動 | 検証済みの保存ROMがあり、コアが使え、処理中でない |
| EXIT TO MiSTer | 管理画面を終了 | 処理中でない |

### 候補の一覧

- タイトル、READER SUPPORTED／UNSUPPORTED の表示、選択中の候補の詳細と対応可否の理由を表示する。
- 案内：
  - READER SUPPORTED は「リーダーの読み出し処理が対応している」という意味で、タイトル・版が実物と一致する保証ではない。
  - 部分ハッシュは別のタイトルや版にも一致し得る。
  - 全体ハッシュが一致するまで、タイトルと版は未確定。
  - 選んだタイトルの全体ハッシュに一致した場合だけ保存する。
- 自動判定グループのときは「選択は任意。DUMPが全体ハッシュで自動判定する」と案内する。
- 複数候補を検出しても、まずメイン画面を表示する。一覧は SELECT CARTRIDGE を選んだときだけ開く。

### 確認画面

- DUMP、GAME START、EXIT で表示する。選択肢は YES と NO で、既定は NO。上・左で YES、下・右で NO。決定で確定。戻るは取り消し。
- 確認の文言：DUMP は「Start reading the selected cartridge?」（自動判定のときは「Read the cartridge and pick the title by hashes?」）、GAME START は「Start the verified game?」、EXIT は「Exit to MiSTer?」。
- 読み出し中の戻るは、安全な区切りでの中止を要求する（「Stopping safely...」を表示）。保存前に中止すれば新規ROMを保存しない。保存の書き込みが始まっていれば、その完了を優先する。

### 進捗

- 段階名と24桁の進捗バー、パーセントを表示する。

## 初期カーソルと遷移

| 自動確認後の状態 | 初期カーソル | SELECT CARTRIDGE |
|---|---|---|
| 候補が複数（自動判定できる組を含む） | SELECT CARTRIDGE | 表示・有効 |
| 候補1件・読み出し対応 | DUMP CARTRIDGE | 表示・有効（開くと1件のみ） |
| 候補1件・未対応 | CHECK / RETRY | 表示・有効（未対応の理由を確認できる） |
| 未挿入・候補なし | CHECK / RETRY | 表示・無効 |

- 候補が最初に現れたときだけカーソルを進める。ポーリングのたびには動かさない。
- 候補の選択後は、対応済みなら DUMP へ、未対応なら SELECT に留める。
- 取り込み・検証の完了後は GAME START へ進む。
- 候補の集合が変わったら、メイン画面に戻し、選択を破棄する。

## 入力

- 方向キーの矢印キー列（`ESC [ A` など）と、`w a s d`、Tab（下）、Enter／Space（決定）、`q`／Backspace／単独のEsc（戻る）を解釈する。
- Escの単独入力は、続きの文字が120ミリ秒来なければ「戻る」とみなす。
- 1回の入力処理につき最初の1操作だけを扱い、直後の入力は入力バッファごと破棄する（0.15秒）。処理の完了直後は0.3秒、入力を無視する（連打による誤操作を防ぐ）。

## 処理構成

- 画面のループは1スレッド。リーダーに触れる処理（poll、retry、select、capture、prepare_game）は、1つのワーカーに1度に1つだけ依頼する。
- 状態確認（poll）は、メイン画面で、確認画面の表示中でなく、前回から0.5〜0.7秒経ったときに依頼する。
- 処理中は、上下の操作でカーソルだけを動かせる。
- 進捗は、ワーカーからキューで受け取る。進捗のコールバックは、中止の要求を確認して例外を投げる。

### 結果の反映

- poll／select：状態をメニューに反映し、その機種のコアが使えるかを再確認する。select のあとは、対応済みなら DUMP、そうでなければ SELECT にカーソルを置く。
- capture：保存済みを真にして GAME START にカーソルを置く。新規保存なら「Saved and verified. Select GAME START.」、既存の同一ファイルなら「Already saved; identical file verified.」、別名保存なら「Saved with hash suffix; existing file preserved. GAME START ready.」を表示する。
- launch：端末を元に戻し、MGLを使って起動要求を送って終了する。要求の送信に失敗したら端末に戻り、エラーを表示する。

### エラー

- 例外が起きたら、メッセージを（ASCIIに丸めて）表示し、候補と選択を破棄してカーソルを先頭に戻し、「Check cartridge/USB connection; select CHECK / RETRY.」などの復旧の案内を表示する。ゲーム起動の失敗は「Check game/core settings; select CHECK / RETRY.」。
- 詳細は `runtime/manager.log` に、日時、例外名、内容を追記する。ログへの書き込みに失敗しても処理は続ける。
- ログが1MiBに達したら `manager.log.1` へ移し（以前の `.1` は置き換える）、新しいログを始める。SDカード上で際限なく大きくならないようにするため。
- 通信エラー後は自動で再接続しない。CHECK / RETRY で再接続する。中止された後だけ、自動のポーリングを再開する。

## 二重起動の防止

- ロックファイルに排他ロック（非ブロッキング）を取る。取れなければ、別のインスタンスが動作中として起動しない。
- 同じリーダーを使う別のコマンドを同時に動かさない。

## ゲーム起動と復帰

- GAME START では、リーダーを解放し、選択したタイトルの保存済みROMをヘッダー・PRG・CHR・全体で再照合してから、MGLで対応コアとROMを指定して起動する。管理画面は終了する。
- 起動用のMGLは、アプリの `runtime/` に生成する。
- ゲームからConsoleModeへの復帰は、MiSTer側の操作（Reboot）で行う。管理画面は、ゲームの終了を検出して再表示する常駐機能を持たない。
- 保存したROMをConsoleModeの一覧へ反映するには、ConsoleMode側のデータベースを再構築する。GAME STARTでの直接起動には、一覧用のデータベースの再構築は不要。
- 選択を変えると保存済みROMの照合対象も変わる。選択前のゲームを代わりに起動することはない。
- カートリッジを抜いただけ（空・複数挿入・未知の状態）では選択を残し、保存済みのゲームを GAME START で起動できる。読み出せるカートリッジが新たに挿されたら選択を解除する。同じヘッダーのカートリッジを挿し直したときは、DB照合済みのタイトルを引き継ぐ。

## 保存先

- 起動時の保存先は、設定のNESの保存先。以降は判定された機種ごとの保存先へ切り替わる。`--output-dir` を指定した場合は固定。
- 設定先に同名で内容が異なるファイルがある場合は、上書きせず、別名の保存になる。

## 試験

- 画面の描画、キー入力のデコード、メニューの有効条件と並び、初期カーソル、候補一覧、確認、進捗、エラーからの復帰、端末サイズによる切り詰めを、模擬サービスと模擬端末で検証する。
